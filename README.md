# Anoop Portfolio V4 — Clear & Animated

This version focuses on **clear typography, strong contrast and professional motion**.

Included:
- `index.html`
- `style.css`
- `script.js`
- `assets/profile.jpeg`
- `assets/Anoop_Resume.pdf`

Features:
- Clear readable text with high contrast
- Dark black / purple / cyan theme
- Animated loader
- Scroll progress
- Soft cursor point + aura (no cursor ring animation)
- Magnetic buttons
- Animated hero typography
- Profile image shine and subtle motion
- Floating information card
- Scroll reveal animations
- 3D project cards
- Animated queue and travel planner mockups
- Responsive mobile navigation
- Reduced-motion accessibility support

Open `index.html` in a browser or use VS Code Live Server.
